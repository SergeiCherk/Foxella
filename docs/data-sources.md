# Источники данных

Здесь честно описано, откуда взята база продуктов, насколько ей можно доверять и как её проверить.

## Что в базе

| Файл | Содержимое |
|---|---|
| `src/nutrition_bot/data/foods.csv` | 271 продукт, из них 70 готовых блюд: калории, белки, жиры, углеводы и клетчатка на 100 г, состояние (сырой, готовый, «как есть»), категория, синонимы |
| `src/nutrition_bot/data/measures.csv` | 371 бытовая мера («половник», «горсть», «чайная ложка», «грудка», «тарелка», «кусок», «бокал») с весом в граммах |
| `src/nutrition_bot/data/food_sources.csv` | откуда взяты значения каждого продукта: номер записи USDA (`fdc_ids`) или способ расчёта |
| `src/nutrition_bot/data/dish_recipes.csv` | состав домашних блюд (борщ, пельмени, оливье): продукт из `foods.csv` и граммы |

Сырые и готовые продукты разведены на разные строки («Рис белый (сухой)» и «Рис белый (варёный)»). У готового продукта есть ссылка на сырой и коэффициент выхода: граммов готового из одного грамма сырого. Он нужен, чтобы в списке покупок «варёный рис» превращался в «сухой рис».

## Откуда взяты значения

Калорийность, белки, жиры, углеводы и клетчатка на 100 г заданы для каждого продукта в `food_sources.csv` одним из пяти способов:

| Способ | Сколько | Что значит |
|---|---|---|
| `usda` | 197 | значения одной записи USDA FoodData Central, набор SR Legacy (выпуск 2018-04) |
| `usda_mix` | 3 | среднее двух записей USDA: фарш говядина+свинина (сырой и готовый), зелень (петрушка+укроп) |
| `derived` | 17 | варёные крупы, макароны и бобовые: значения сухого продукта из USDA, делённые на коэффициент выхода |
| `label` | 14 | российские продукты, у которых нет точного аналога в USDA: творог, кефир, сметана, молоко 2,5 %, йогурт 2,5 %, масло 82,5 %, моцарелла в рассоле, докторская колбаса, сосиски, майонез 67 %. Значения пока прежние (типичные справочные) и **ждут сверки по этикеткам** |
| `recipe` | 40 | домашние блюда: сумма продуктов рецепта из `dish_recipes.csv`, делённая на вес блюда. `water` добавляет только вес, `cooked_weight` задаёт вес готового блюда, когда при жарке или выпечке уходит вода |

**Почему варёные крупы считаются, а не берутся из USDA.** Калорийность каши зависит от того, сколько воды впитала крупа. USDA варит заметно жиже, чем принято у нас (например, варёная гречка у них 92 ккал при выходе 3,8, а рассыпчатая у нас ближе к выходу 2,5–3). Если взять их цифру, бот занижал бы калорийность привычной каши, а при похудении это худший вид ошибки. Поэтому сухая крупа берётся из USDA, а варёная это «сухая ÷ выход»: вода питательных веществ не добавляет, и меню всегда согласовано со списком покупок. Тест `tests/unit/test_usda_import.py` проверяет это равенство. Коэффициенты выхода это оценки; точнее всего их уточнить, один раз сварив и взвесив крупу.

**Готовые блюда.** Они нужны для «съел(а)»: человек пишет «тарелка борща, 2 куска пиццы», и бот должен это понять. Фастфуд, напитки, выпечку и десерты (пицца, бургер, кола, пиво, торт, круассан, омлет) берутся из USDA. Русских домашних блюд в USDA нет, поэтому они считаются по типичному рецепту из продуктов базы: калории считает импорт, а не человек на глаз. Рецепты это оценки «средней» домашней версии; реальная тарелка борща может отличаться на 20–30 %. В меню и в список продуктов для нейросети готовые блюда не попадают (категория `dish`): меню собирается из продуктов.

**Как выбирались записи USDA.** Для каждого продукта взята самая близкая к тому, что продаётся у нас: «Говядина постная» это top round, «Свинина нежирная» это вырезка (tenderloin), «Гречка» это обжаренная ядрица (roasted groats), «Сыр твёрдый» это эдам. Название записи записано в колонке `note`. Мясо, рыба, яйца и картофель в готовом виде берутся из USDA напрямую, а их коэффициенты выхода (потеря воды при готовке) остаются оценками проекта.

Обновить значения после правки `food_sources.csv` или выхода новой версии данных:

```bash
# скачайте "SR Legacy" (CSV) с fdc.nal.usda.gov/download-datasets и распакуйте в data/usda/
uv run python scripts/import_usda.py           # показать, что изменится
uv run python scripts/import_usda.py --write   # записать в foods.csv
uv run python scripts/validate_data.py
uv run pytest
```

Папка `data/usda/` не попадает в git. Если она есть, тест дополнительно проверяет, что `foods.csv` совпадает с USDA.

Веса бытовых мер (сколько граммов в «половнике» или «горсти») это **ориентировочные оценки**, а не измерения. У продуктов, добавленных вместе с импортом USDA (перловка, фарши, ягоды и др.), веса стакана, ложки и штуки взяты по таблице порций USDA (`food_portion`, CC0), американский стакан 240 мл пересчитан в наш 250 мл; «половник», «горсть» и «пучок» и у них оценки. Объём стакана принят равным 250 мл. Для круп и каш ложки не используются: только стакан, горсть, половник и тарелка.

Тексты рецептов 30 встроенных блюд написаны для этого проекта. Тексты рецептов, которые предлагает нейросеть, создаются на лету и проходят проверку (в них запрещены упоминания калорий, количеств, ссылок и продуктов не из состава блюда).

## Как данные проверяются автоматически

`uv run python scripts/validate_data.py` (и тесты) проверяют:

- нет повторов кодов и названий, все состояния и категории известны;
- числа конечны и неотрицательны, белки + жиры + углеводы не больше 100 г, клетчатка не больше углеводов;
- калории согласуются с БЖУ по коэффициентам Этуотера (4, 4, 9 ккал на грамм) в пределах ±12 % (но не менее 20 ккал); кроме алкоголя (пиво, вино, крепкий): его 7 ккал на грамм в БЖУ не входят;
- у каждого блюда-рецепта есть состав, все продукты состава существуют и сами не являются блюдами;
- у готового продукта есть существующий сырой, коэффициент выхода в разумных пределах, и энергия готового с учётом выхода в пределах от 0,75 до 1,25 энергии сырого;
- у каждого продукта есть хотя бы одна мера, меры не дублируются, вес меры положителен.

Что проверка **не** ловит: правдоподобную, но неверную цифру, у которой всё сходится (например, одновременно неверные калории и БЖУ в пределах допуска). Веса мер она проверяет только на здравый смысл.

## Что ещё сверить (рекомендуется до публичного запуска)

1. **14 продуктов `label`.** Для каждого возьмите 2–3 упаковки массовых марок, перепишите значения на 100 г и внесите среднее в `foods.csv`. Цифры с упаковки это факты, их можно использовать; целые таблицы из российских справочников с неясной лицензией копировать не нужно. В `food_sources.csv` замените примечание на марки и дату проверки.
2. **Коэффициенты выхода круп.** Сварите 100 г сухой крупы как обычно и взвесьте готовую. Поправьте `yield_factor` в `foods.csv` и выполните `uv run python scripts/import_usda.py --write`: варёный продукт пересчитается сам.
3. **Меры.** Один раз взвесьте на кухне «половник» своего размера, «горсть», «ложку».
4. После правок:

   ```bash
   uv run python scripts/validate_data.py
   uv run pytest
   uv run python -m tests.render_examples   # обновить примеры диалогов
   ```

## Что сознательно не используется

- **Open Food Facts** (лицензия ODbL требует указания источника и распространения производных баз на тех же условиях). Данные оттуда в репозиторий не копировались.
- **Российские справочные таблицы** с неясной лицензией. Не копировались.
- **Сторонние архивы рецептов**, собранные парсерами с сайтов, без лицензии на содержимое. Тексты и фото принадлежат сайтам и авторам. Такие архивы использовались только как справочник для анализа популярных ингредиентов (результат не публикуется), сами рецепты в проект не включены.

## Дисклеймер

Бот не заменяет врача и не ставит диагнозов. Расчёты ориентировочные. Если есть заболевания, беременность, расстройства пищевого поведения или сомнения, посоветуйтесь со специалистом. Бот рассчитан только на взрослых (18+).
