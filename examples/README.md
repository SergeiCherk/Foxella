# Примеры диалогов

Это не придуманные картинки, а **настоящие ответы бота**: диалоги создаёт скрипт `tests/render_examples.py`, который отправляет сообщения в настоящие обработчики (Telegram подменён, нейросети нет, блюда встроенные).

| Файл | Что показывает |
|---|---|
| [01-znakomstvo.md](01-znakomstvo.md) | анкета, расчёт нормы, проверка срока достижения цели |
| [02-menu.md](02-menu.md) | меню на день: продукты текстом, уточняющие вопросы, порции в мерах |
| [03-pokupki-i-udalenie.md](03-pokupki-i-udalenie.md) | список покупок (готовое → сырое), профиль, удаление данных |
| [04-srez.md](04-srez.md) | день не по плану: выбор примерного размера |
| [05-srez-spiskom.md](05-srez-spiskom.md) | то же, но списком съеденного: подсчёт по базе и подтверждение |

Обновить после изменения текстов, данных или норм:

```bash
uv run python -m tests.render_examples
```

Скриншоты настоящего Telegram, когда запустите бота, лучше положить рядом.
